# Presentation Deck Architect

Develop a presentation through explicit editorial decisions rather than generating an entire deck from a single brief. The workflow separates structure, hook, opening, and slides so that each stage can use your selected output from the previous stages.

## Available Workflow

- [Guided workflow](guided/README.md): four sequential prompts with shared presenter, topic, objective, and audience context. Each rendered prompt can be used in a fresh AI chat.
- [Infrastructure example](guided/example.md): a Developer Advocate presentation for SREs about automation, configuration drift, and an illustrative migration scenario.

The workflow requires source and date information for factual claims, marks unavailable evidence as `UNVERIFIED`, and offers nonnumeric alternatives instead of invented statistics.
